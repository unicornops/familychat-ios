# Reporting a Vulnerability

**If you've found a security vulnerability in the Family Chat iOS client, please report it privately to
security@safechat.family rather than opening a public issue.**

This app is a fork of [Element X iOS](https://github.com/element-hq/element-x-ios). If the vulnerability is in
upstream code that we have not modified, please also consider reporting it to Element at security@element.io so
that every downstream app benefits from the fix. See
https://element.io/security/security-disclosure-policy for their policy.
